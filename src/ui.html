这是什么

一个单文件网页工具：把要发给 AI 的内容先脱敏，拿回答案后一键还原。全部计算在你的浏览器里完成，不联网、不上传、不安装任何东西。把这个 HTML 文件发给同事，双击就能用。

四步用法

  • 粘贴或拖入：支持 .docx / .xlsx / .pptx / .txt / .md / .csv，也可以直接复制 Excel 的表格区域（保留制表符）。
  • 扫一眼清单：误伤的按「放行」，漏掉的加进自定义词库。
  • 复制：把右侧脱敏稿粘给 ChatGPT / Claude / 豆包 / Kimi，网页版或 App 都行。
  • 还原：把 AI 的回复贴到「还原 AI 回复」页，一键换回真实名称与原始金额。

代号会带角色

投融资文档里，标的、买方、卖方、顾问全叫"企业A/B/C"是灾难——AI 分不清谁是谁。所以工具会读上下文，给代号加角色：

【标的A】 标的公司　【买方A】 收购方/投资方　【卖方A】 转让方　【供应商B】　【顾问A】 财务顾问　【律所A】　【股权A】 持股比例

同一家公司的全称和简称（含"以下简称"定义的）会共用一个代号，不会被拆成两家。

财务数据是怎么处理的

默认等比缩放 ×0.618：所有金额同比例变化，毛利率、占比、增速、结构比例全部不变，AI 照样能做测算和敏感性分析，但绝对值不再是真实数字。财务比率（%、倍数、周转天数）默认不脱敏，因为它们本身不敏感且是分析骨架。

识别覆盖：三大表科目行（营业收入、营业成本、EBITDA、经营性现金流…）、多期数据列、银行流水（对方户名、金额、余额）、合同/发票编号、股票代码、投前投后估值、对价、注册资本。

关于数据安全

  • 映射表存在本机浏览器（localStorage），关掉页面不丢，换电脑/换浏览器不通用。
  • 顶栏可以切换项目——一个客户一套映射。换客户请新建项目，别混在一起：代号会串，导出的映射也会把历史客户全带走。
  • 可逆脱敏在法律上属于去标识化，不是匿名化——处理后仍属个人信息，只是风险大幅降低。
